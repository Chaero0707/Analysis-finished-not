# Analysis-finished-not
How to Install the Chrome Extension Manually:

Step 1: Create a Project Folder
1. Create a new folder on your computer (e.g., on your Desktop).
2. Name the folder "ogs-alert-blocker".
3. Save the 'manifest.json' and 'content.js' files inside this folder.

Step 2: Open Chrome Extensions Page
1. Open Google Chrome.
2. Type "chrome://extensions/" in the address bar and press Enter.

Step 3: Enable Developer Mode
1. Look at the top-right corner of the Extensions page.
2. Turn ON the "Developer mode" toggle switch.

Step 4: Load the Extension
1. Click the "Load unpacked" button in the top-left corner.
2. Select the "ogs-alert-blocker" folder you created in Step 1.
3. Click "Select Folder" (or "Open").

The extension is now installed and will automatically block the "Analysis finished" alerts on Online Go Server!
